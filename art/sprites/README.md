## 직접 읽은 것 / 추정한 것
- **직접 읽음(정확)**: 사진 1 큰 정면 2장(17×40, 17×41), 사진 2 전체(정수 3px 격자, 얼굴 빈 공간·땋은 가닥 사이 투명 유지). 사진 5도 격자가 잘 맞아 선명.
- **추정 포함**: 사진 1 걷기 시트(작은 그림은 JPG 번짐이 큼). 중앙 정면 프레임을 큰 정면 그림과 비교해 측정: **맨몸 91.5%, 의상 74.3% 도트 일치**. 나머지 11개 프레임도 비슷한 수준으로 보면 된다(애매한 색은 이웃 칸 투표로 확정, 번진 흰 테두리·잡티 제거). 흰 머리 하이라이트는 외곽선 안에 갇힌 흰색을 불투명 흰색으로 채움 → 후면 머리 내부 명암 디테일은 뭉개졌다.
- **한계**: 사진 4(1.8px)와 사진 3(2.0px, 원본이 부드럽게 번진 그림)은 도트 경계가 불분명해 모양·명암만 근사. 사진 3은 정확한 도트 복원이 아니다.
- 사진 2의 흰 세트/짙은 세트 실루엣 겹침(IoU) 평균 0.988 — 같은 격자에 놓여 기준점이 같다.
